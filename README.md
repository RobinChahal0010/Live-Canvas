# 🎨 LiveCanvas

**LiveCanvas** is a real-time collaborative online whiteboard for brainstorming, planning, and teamwork. Users can draw, add sticky notes, vote on ideas, and collaborate instantly.

## ✨ Features

-  Real-time whiteboard collaboration
- 📝 Sticky notes & freehand drawing
- 👍 Idea voting
- 👥 Private breakout rooms
- ⏪ Board history replay
- 📌 Version history & restore
- Low-latency synchronization

## 🏗️ Tech Stack

- **Frontend:** React.js, TypeScript
- **Backend:** Spring Boot
- **Database:** PostgreSQL
- **Real-time:** WebSockets
- **Cache:** Redis
- **Auth:** JWT
- **Deployment:** Docker

## 🚀 Use Cases

- Classroom collaboration
- Remote team meetings
- Design workshops
- Sprint planning
