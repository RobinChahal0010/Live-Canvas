# 🎨 LiveCanvas

**LiveCanvas** is a real-time collaborative online whiteboard that enables teams to brainstorm, plan, and collaborate from anywhere. Users can draw, add sticky notes, vote on ideas, and see every change instantly.

## ✨ Features

- 🖍️ Real-time collaborative whiteboard
- 📝 Sticky notes and freehand drawing
- 👍 Idea voting
- 👥 Breakout rooms with private annotations
- 🌐 Shared main board visible to all participants
- ⏪ Replay complete board history
- 📌 Version control to restore previous board states
- ⚡ Low-latency synchronization for seamless collaboration

## 🚀 Use Cases

- Classroom brainstorming
- Remote team meetings
- Hackathon planning
- Design thinking workshops
- Agile sprint planning

## 🏗️ Tech Stack

- **Frontend:** React.js, TypeScript
- **Backend:** Spring Boot
- **Database:** PostgreSQL
- **Real-time Communication:** WebSockets
- **Caching:** Redis
- **Authentication:** JWT
- **Deployment:** Docker

## 📖 How It Works

1. Create or join a whiteboard.
2. Collaborate in real time using drawings, notes, and voting.
3. Split into breakout rooms for private discussions.
4. Merge ideas back onto the main board.
5. Replay the entire session or restore previous versions anytime.
